## 工作日依据与年度维护

“中国工作日”按国务院官方放假调休通知判断，包含周末调休上班日，并排除法定休息日。[2026 年官方通知的政府网站转载](https://www.beijing.gov.cn/fuwu/bmfw/sy/jrts/202511/t20251104_4258838.html)已核查；缓存保存在 [china-workday-calendar.json](china-workday-calendar.json)。

当前从 2026-10-12 起至本年年底，没有剩余法定假期或周末补班例外。因此当前每周一至周五的基础日程与这段时间的中国工作日一致：

```ical
BEGIN:VEVENT
DTSTART;TZID=Asia/Shanghai:20261012T090000
RRULE:FREQ=WEEKLY;BYDAY=MO,TU,WE,TH,FR;BYHOUR=9;BYMINUTE=0;BYSECOND=0
END:VEVENT
```

新年度不假设继续使用同样的假期表。晨间任务及原有凌晨任务会按缓存的检查时间获取国务院正式年度通知或更正，保存来源和日期，然后更新同一个晨间任务：用 EXDATE 排除周内假期、RDATE 加入周末补班。保留已有有效未来例外和原任务状态，不创建重复任务。2027 年表在本次核查中尚未取得可靠依据，缓存明确标为 not_verified，后续维护负责补齐；每次运行也先检查当天是否属于已核查的工作日。
